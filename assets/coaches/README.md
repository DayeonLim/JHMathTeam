# Coach photos

Drop each coach's photo in **this folder**, named exactly as listed below.
Until a file exists, the site shows a colored tile with the coach's initials —
so the site works fine even with no photos yet.

## Recommended format
- **Square** images look best (they're cropped to a square).
- ~600×600px is plenty. JPG or PNG.
- Keep file names lowercase with dashes, exactly as below.
